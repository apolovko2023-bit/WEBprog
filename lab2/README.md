## Що реалізовано
- семантична розмітка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- зовнішній CSS підключено через `<link rel="stylesheet" href="css/style.css">`;
- селектори: елемента, класу, id, атрибута (`input[type="email"]`), універсальний (`*`), групування (`h1, h2, h3`);
- навмисний конфлікт правил для абзацу `#company-description` (`p`, `.lead`, `#company-description`) для аналізу каскаду та specificity;
- Box Model з `box-sizing: border-box` для картки вимірювання;
- `display`: `block` (секції), `inline` (`.level`), `inline-block` (картки, навігація);
- `position: relative` для попередження та `position: absolute` для позначки «Увага»;
- `transform` для декоративного елемента датчика;
- `transition` і зміна кольору при наведенні для кнопки та карток.

## Відповіді на контрольні питання

**1. Для чого використовується CSS?**
CSS (Cascading Style Sheets) використовується для оформлення веб-сторінок: кольорів, шрифтів, розмірів, відступів, розташування елементів. Він відокремлює зовнішній вигляд від структури та змісту, які описує HTML.

**2. Які способи підключення CSS ви знаєте?**
- зовнішня таблиця стилів: `<link rel="stylesheet" href="css/style.css">` (використана в роботі);
- внутрішні стилі: тег `<style>` у `<head>`;
- вбудовані стилі: атрибут `style` в елементі;
- імпорт через `@import` в іншому CSS-файлі.

**3. Чим відрізняється селектор елемента від селектора класу?**
Селектор елемента (`p`) застосовується до всіх елементів цього тегу на сторінці. Селектор класу (`.card`) застосовується лише до елементів із відповідним атрибутом `class`, незалежно від тегу, і його можна використовувати багаторазово.

**4. Для чого використовується id?**
`id` ідентифікує один унікальний елемент на сторінці. Його використовують для точкового стилізування (`#company-description`), для якірних посилань (`href="#order"`) та для зв'язку `label[for]` з `input[id]`.

**5. Що робить універсальний селектор `*`?**
Вибирає всі елементи на сторінці. У роботі використано `* { box-sizing: border-box; }`, щоб усі елементи рахувалися за однаковою моделлю розмірів.

**6. Для чого потрібен селектор атрибута?**
Дозволяє вибирати елементи за наявністю або значенням атрибута, наприклад `input[type="email"]` стилізує тільки поле email, не зачіпаючи інші `input`.

**7. Що таке каскад CSS?**
Це механізм, за яким браузер вирішує, яке значення властивості застосувати, коли кілька правил впливають на один елемент. Враховуються важливість правила (`!important`), специфічність селектора та порядок розташування в коді (пізніше правило перемагає при рівній специфічності).

**8. Що таке specificity?**
Це «вага» селектора, за якою визначається, яке правило сильніше. У спрощеній моделі: id > клас/атрибут/псевдоклас > елемент.

**9. Який селектор переможе: `p`, `.warning` чи `#warning`?**
Переможе `#warning`, бо селектор id має найвищу специфічність (1,0,0), клас (0,1,0), а елемент (0,0,1).

**10. Чому CSS-правило може бути перекресленим у DevTools?**
Бо воно було перекрите іншим правилом для тієї ж властивості: з вищою специфічністю або таким самим рівнем, але розташованим пізніше в коді. Перекреслене правило браузер знайшов, але не застосував.

**11. Чим відрізняються margin і padding?**
`padding` це внутрішній відступ між вмістом і рамкою елемента (фон елемента його заповнює). `margin` це зовнішній відступ між рамкою елемента та сусідніми елементами (прозорий).

**12. Що входить до Box Model?**
Від центру назовні: вміст (`width`, `height`), `padding`, `border`, `margin`.

**13. Чим відрізняються block, inline-block та inline?**
- `block`: займає всю ширину рядка, починається з нового рядка, приймає `width`, `height`, `margin`, `padding`;
- `inline`: розташовується в рядку тексту, не переходить на новий рядок, ігнорує `width` і `height`, вертикальні `margin`;
- `inline-block`: стоїть у рядку, як inline, але приймає `width`, `height`, `margin`, `padding`, як block (у роботі використано для карток і навігації).

**14. Для чого потрібен `box-sizing: border-box`?**
Щоб `width` і `height` включали `padding` і `border`. Без нього ширина елемента збільшується на розмір відступів і рамки, що ускладнює розрахунок макета.

**15. Чому зміна CSS-правила іноді не змінює вигляд елемента?**
Можливі причини:
- правило перекрите сильнішим або пізнішим правилом (каскад і specificity);
- помилка в селекторі, назві класу чи властивості, або пропущена дужка/крапка з комою;
- CSS-файл не підключений або шлях у `href` неправильний;
- файл не збережений або браузер показує закешовану версію (потрібно Ctrl+F5);
- властивість не діє на цей тип блока (наприклад, `width` для `inline`).
