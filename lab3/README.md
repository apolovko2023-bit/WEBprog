# Лабораторна робота №3
## Адаптивна верстка веб-сторінки за допомогою Flexbox, CSS Grid та препроцесора SCSS

**Дисципліна:** Веб програмування
**Виконала:** Половко Аліна, група КН-42

## Мета роботи
Набути практичних навичок перетворення створеної HTML/CSS-сторінки на адаптивний інтерфейс із використанням SCSS, Media Queries, Flexbox та CSS Grid.

## Опис проєкту
Адаптивна версія сайту компанії «Акустична варта» (сервіс моніторингу шумового забруднення), створеного в лабораторній роботі №2. Стилі перенесено з CSS у SCSS, сторінка коректно відображається на мобільних пристроях, планшетах і комп'ютерах.

## Структура проєкту
```
lab-3/
├── index.html
├── assets/
│   └── images/
│       └── hero.jpg
├── css/
│   └── main.css          (результат компіляції SCSS)
└── scss/
    ├── _variables.scss
    ├── _mixins.scss
    ├── _base.scss
    ├── _layout.scss
    ├── _components.scss
    └── main.scss
```

## Що реалізовано
- **Meta viewport** у `<head>` для коректного відображення на мобільних пристроях.
- **Модульна структура SCSS** з `@use` (без застарілого `@import`); `main.scss` є точкою входу.
- **Змінні** (`_variables.scss`): кольори, відступи, ширина контейнера, радіус, breakpoints (`$bp-tablet: 768px`, `$bp-desktop: 1024px`).
- **Mixins** (`_mixins.scss`): `respond-to` (media query), `flex-center`, `container`, `card`.
- **Nesting** не глибше 3 рівнів.
- **Mobile First**: базові стилі для мобільного екрана, розширення через `min-width`.
- **Flexbox**: header, навігація, footer, внутрішня структура карток.
- **CSS Grid**: hero, сітки «Поточний моніторинг» і «Напрямки роботи», форма.
- **clamp()** для адаптивної типографіки заголовків.

## Адаптивна поведінка

| Компонент | Mobile (<768px) | Tablet (768–1024px) | Desktop (>1024px) |
|---|---|---|---|
| Header і навігація | у колонку | у рядок | у рядок |
| Hero | 1 колонка | 2 колонки | 2 колонки |
| Поточний моніторинг | 1 колонка | 2 колонки | 5 колонок |
| Напрямки роботи | 1 колонка | 2 колонки | 4 колонки |
| Форма | 1 колонка | поля у 2 колонки | 2 колонки (поля + опис) |
| Таблиця | прокрутка всередині контейнера | | |
| Footer | у колонку | у рядок | у рядок |

## Компіляція SCSS
SCSS скомпільовано у `css/main.css` за допомогою розширення Live Sass Compiler у VS Code. У `index.html` підключено саме `css/main.css`.

## Перевірка
Адаптивність перевірено в DevTools (Device Toolbar) на ширинах приблизно 375 px, 768 px, 1024 px та від 1200 px. Горизонтальної прокрутки на рівні `body` немає.
