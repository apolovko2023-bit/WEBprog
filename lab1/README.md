# Лабораторна робота 1
## Імплементація блогу «Мої 3 найкращі міста світу». Розміщення проєкту в репозиторії GitHub

**Дисципліна:** WEB-програмування
**Виконала:** Половко Аліна, група КН-42

## Мета роботи
Набути практичних навичок створення багатосторінкового статичного web-сайту на HTML, використання системи контролю версій Git та публікації проєкту через GitHub Pages.

## Опис проєкту
Статичний блог про три міста, які мені найбільше подобаються: Київ, Париж, Токіо. Для кожного міста створена окрема сторінка з зображенням, описом, фактами, визначними місцями та особистою оцінкою. Також є сторінка з формою для пропозиції міста до наступного рейтингу.

## Структура проєкту
WEBprog/
├── index.html — головна сторінка
├── city-kyiv.html — сторінка Києва
├── city-paris.html — сторінка Парижа
├── city-tokyo.html — сторінка Токіо
├── form.html — форма «Запропонувати місто»
└── README.md — опис проєкту


## Що реалізовано
- семантична розмітка (`header`, `nav`, `main`, `section`, `article`, `footer`);
- однакова навігація на всіх сторінках за допомогою відносних посилань;
- зображення з осмисленими `alt`;
- зовнішні посилання на додаткову інформацію про міста;
- форма з елементами `input`, `label`, `select`, `option`, `textarea`, `button` та обов'язковими полями (`required`).

## Виконані етапи
1. Спроєктовано структуру сайту та навігацію.
2. Створено HTML-сторінки та форму.
3. Перевірено посилання, зображення та форму локально.
4. Ініціалізовано Git-репозиторій (`git init`, `git add .`, `git commit`).
5. Створено репозиторій на GitHub і виконано `git push`.
6. Налаштовано GitHub Pages (Deploy from a branch, `main`, `/(root)`).
